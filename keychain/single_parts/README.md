# Piezas sueltas (si Elegoo da error de purga)

Si aparece *«La matriz de volúmenes de purga no coincide»* incluso a un color, usa estos archivos de **un solo objeto**:

| Archivo | Uso |
|---------|-----|
| `blanco_fondo.3mf` | Mitad trasera NFC |
| `blanco_frente.3mf` | Mitad frontal |
| `naranja_texto.3mf` | Texto (solo si imprimes aparte) |
| `llavero_un_color.3mf` | Todo junto, 1 color (prueba de laminar) |

También hay `.stl` equivalentes.
