# CeluMB (Next.js)

App real de inventario / ventas / crédito. Datos en Supabase.

## Hostinger Web Apps

- **Directorio raíz:** `celumb-app`
- **Build:** `npm install && npm run build`
- **Start:** `npm start`
- **Node:** 20 (o 22 si 20 no aparece)
- **URL prevista:** https://celumb.mtvalpa.com

Variables (valores solo en hPanel, nunca en el repo):

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `DATABASE_URL`
- `CELUMB_AUTH_SECRET`
- `CELUMB_PUBLIC_URL=https://celumb.mtvalpa.com`

Ver `HOSTINGER.md`.

El archivo `celumb` en la raíz del repo es el HTML estático de preview — no usarlo como app Node.
